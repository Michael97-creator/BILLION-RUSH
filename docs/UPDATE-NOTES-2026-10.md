# Update notes — October 2026

This is a targeted update to the existing Billion Rush project.

- The Version 1 plan remains ad-free and Nigeria-first, with NGN pricing.
- Regular lifeline packages are now ₦200 for 1 use or ₦500 for 3 uses per lifeline.
- Extra Time is ₦200 for 1 use or ₦800 for 5 uses; each use adds 10 seconds.
- Second Chance is ₦300 for 1 use or ₦500 for 2 uses, with no free uses and no checkout after Game Over.
- The existing ₦2,000 Complete Lifeline Bundle is retained.
- Active sessions are invalidated when the app is left; active progress is not saved or resumed.
- Server-side Paystack and inventory source code has been added but still needs migration/function deployment, test-mode configuration, and end-to-end testing.
